# 낭만공작소 작품 소개 및 제품 페이지

- 공식 주소: https://myclubmakers.com/nangman/
- 공개 상세페이지: /nangman/products/{id}/
- 메인 갤러리: WOONGTO, 인생4초, 채CINE, 낭만페이지, 시날로아, 사투링고 6개; 추가 작품: 제작 중인 애니메이션 우울폭주성탄절, 에세이텔라, 메모텔라.
- 제외: 아버지 이야기 노트(아버지연대기), 기분풍선, 벽돌깨기. 해당 원본 코드는 삭제하지 않음.
- 디자인 원칙: 큰 '재미있는 건 직접 만들어요' 히어로, 실험실·습작·프로토타입 등 아마추어 인상을 주는 문구 제거. '낭만공작소 작품 소개'로 첫 화면을 바로 시작.
- 개별 제품 상세: 각 페이지 고유 SEO, 기능 6개, 사용 순서 4개, 대상 독자, 플랫폼/상태, 이용 FAQ, 최종 다운로드·체험 CTA.
- 실제 구매 연결: 출시한 세 앱은 App Store 공식 링크로 이동(무료 다운로드 후 앱 내 구입 가능). 가격은 앱/스토어에서 확인. 자체 결제나 인앱 결제를 사이트에서 흉내 내지 않음.
- 미출시: 낭만페이지·메모텔라에는 허위 구매 버튼 없음. 시날로아·사투링고·에세이텔라는 실제 웹페이지로 연결. 우울폭주성탄절은 제작 중이며 기존 /blue-christmas/ 제작 페이지로 연결.
- 참조 사이트: 사용자가 제시한 https://lessismore-7e070.web.app/ . 해당 사이트의 실제 콘텐츠 직접 추출은 접근 제한으로 불가하여 구조만 '제품별 스크롤형 랜딩페이지' 요구대로 제작.
- 아이콘은 기존 GitHub 원본 에셋 재사용. 시날로아, 우울폭주성탄절 이미지는 실제 작품 장면(앱 아이콘 아님).
- PWA 캐시는 제품 상세 9개 경로도 등록.
- 배포 순서: branch PR -> Cloudflare Pages Preview/검수 -> main 병합 -> 배포 상태 확인.

## 카드뉴스 소개 복원 (2026-10-10)
- 메인 갤러리의 9개 작품 카드를 누르면 이전 버전의 편집형 5장 카드뉴스를 먼저 보여준다. (데스크톱 및 모바일)
- 카드뉴스: 작품별 컬러, 실제 앱 아이콘/게임 장면, 등장 애니메이션, 도트 진행 표시, 좌우 스와이프·키보드 화살표·닫기, PNG 저장(1080×1350), 링크 공유 및 딥링크(`#/story/{id}/{1~5}`).
- 5장 마지막 화면에서 제품 상세페이지와 별도 앱 다운로드/웹 체험으로 이동. 아직 출시 전인 서비스는 허위 구매 버튼 없이 상세 소개만 노출.
- 개별 제품 상세페이지(`/nangman/products/{id}/`)는 그대로 유지. Ctrl/Meta+클릭 및 JS 불가 시 기존 `<a href>` 상세페이지 접근 가능.
- 주입 파일: `public/nangman/story.js`, `public/nangman/story.css`; 본문 `app.js`에서 카드뉴스 보기 안내, `index.html`에서 스크립트/스타일 로드.
- PWA cache v6에서 두 신규 파일 precache. UI 이동·스크롤·iPhone Safari 모달 스와이프·링크 검증 필요.
