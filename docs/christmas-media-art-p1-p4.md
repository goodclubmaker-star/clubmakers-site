# 골프채공작소 크리스마스트리 — 미디어아트 P1~P4 (2026-11-20)

실제 적용 위치: `public/christmas/index.html`
홈페이지 팝업: `src/components/ChristmasPopup.astro`
공개 경로: `/christmas/`

## P1. 트리 시각적 완성도

- 황금빛 별과 빛줄기, 빛이 이동하는 3중 나선형 가랜드.
- 트리 뒷면/앞면의 눈송이를 분리해 겹침과 원근감을 연출. 모바일에서는 저전력 모드에 따라 밀도 축소.
- 유리구슬, 하트, 별 이름 장식. 미리 만든 캔버스 스프라이트를 사용하여 렌더링 부하 감소.
- 트리 시작 시 약 1초의 부드러운 등장 효과. OS의 모션 감소 설정에서는 생략.

## P2. 폭죽 공연

- 평소에는 양옆에서 간헐적으로 폭죽 발사.
- 이름 입력/이름 터치 후에는 9발의 시간차 축하 공연(0.35~3.70초 발사, 마지막 상단 중앙 황금빛 피날레).
- 로켓 상승, 불꽃 분열, 중력에 의한 낙하. 과도한 원형 CSS 링 및 테스트 버튼 없음.
- 소리가 나는 폭죽 효과나 TTS 기능 없음. 기존 캐롤 파일과 버튼은 유지.

## P3. 나만의 이름

- 이름 입력 옆에서 별(`star`), 하트(`heart`), 유리구슬(`glass`) 선택.
- 선택은 `public.christmas_tree_names.ornament_type`에 저장됨. 기존 행의 기본값은 `star`.
- 이름 저장 후 해당 페이지로 자동 이동/회전하고, 축하 인사 뒤 트리 장식으로 등장.
- 이름을 터치하면 해당 장식으로 회전하며 강조. 재방문 시 `내 이름 찾기`로 이전 기록 접근.
- 브라우저 로컬스토리지 키: `cm-christmas-own-v2`, `cm-christmas-ornament`.
- 공유 딥링크: `/christmas/?wish=<숫자 id>`. 공개된 이름 중 첫 500개 밖의 ID도 개별 조회 가능. 다른 사람의 링크 방문이 자신의 저장 이름을 덮어쓰지 않음.

## P4. 이미지 카드와 공유

- 캔버스에 현재 트리/불꽃 장면을 합성한 세로형 PNG 카드(900×1600, 이름+메리 크리스마스+골프채공작소).
- 화면 왼쪽의 `친구에게 공유`: 브라우저의 Web Share API가 있으면 OS 기본 공유 창을 사용. 지원 기기/앱에서는 PNG+링크를 함께 전달.
- PNG 공유가 불가능하면 링크 공유, 공유 API도 없으면 링크 복사로 폴백.
- `카드 저장`은 PNG 다운로드용 버튼이며 이름을 선택/저장한 경우 노출.
- 홈페이지 iframe에 `allow="autoplay; web-share"` 적용. 카카오톡 SDK 키는 필요하지 않으며, 카카오톡 앱이 기기에 있고 OS 공유 시트에 보이면 직접 선택.
- 이름 입력 직후의 폭죽 렉을 피하려고 PNG 사전 생성은 축하 연출 이후 유휴 시간에 실행.

## 성능과 검증 범위

- 기존 모바일 약 30fps 목표, 작은 화면 DPR ≤1.5, 저속 기기 자동 파티클 축소.
- 기본 연출/공유 UI에 외부 JS 라이브러리나 AI 모델 다운로드 없음.
- 확인한 것: JavaScript 구문 검사, 모의 DOM/캔버스 렌더링, DB `ornament_type` 컬럼/제약, 공유 PNG 파일/저장 버튼, 기본 이름 저장, 500개 밖의 이름 딥링크.
- 미확인: Cloudflare Pages 실배포 상태, iPhone Safari와 KakaoTalk 실기기 공유, 실제 FPS/발열. 배포 확인과 실기기 확인 전에는 이들을 완료로 표시하지 않을 것.

## 회귀 검증

1. 캐롤 켜기/끄기, 세로/가로 화면 크기, 홈 팝업/전체 화면, 트리 회전.
2. 이름 12자 이하로 별/하트/구슬 각각 저장 → 다른 브라우저에서 장식 종류 유지.
3. 저장 후 5초 이내 메리 크리스마스 미디어아트와 단계적 폭죽, 장식 등장.
4. 다른 방문객의 이름 클릭 → 강조/폭죽, 본인의 로컬 저장 이름은 불변.
5. 이전 저장 이름 클릭, 재방문 후 내 이름 찾기.
6. 사진 저장 후 PNG를 실제로 열어 확인, iPhone/Android 기본 공유 메뉴에서 카카오톡 선택 및 링크 열기.
7. `?wish=<id>` 방문 시 이름 강조; 500개 목록 바깥에 있는 ID도 조회해 보여주기.
8. 느린 모바일에서 스크롤/회전/이름 입력 끊김이 과도하지 않은지 확인.
