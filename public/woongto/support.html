주요 기능

  • GPS 활동 기록
  • 거리, 시간, 페이스, 현재 고도 및 누적상승 기록
  • 걷기, 러닝, 등산, 트레일러닝 활동 관리
  • 코스 검색 및 저장
  • GPX / TCX / FIT 파일 가져오기
  • 활동 기록함 및 월간 통계
  • 3D 경로 리플레이
  • 활동 스토리 생성 및 공유

기본 문제 해결

  • GPS 기록이 정상적으로 시작되지 않으면 iPhone 설정에서 WOONGTO의 위치 권한을 확인해 주세요.
  • 정확한 기록을 위해 야외에서 위치 신호가 안정된 뒤 활동을 시작해 주세요.
  • GPX / TCX / FIT 가져오기가 되지 않으면 파일이 손상되지 않았는지 확인해 주세요.
  • 문제가 계속되면 iPhone 모델, iOS 버전, 문제 발생 화면과 함께 이메일로 알려주세요.

WOONGTO는 활동 기록을 위해 위치 정보 등 필요한 데이터를 사용할 수 있습니다. 자세한 내용은 개인정보 처리방침을 확인해 주세요.

WOONGTO Support

WOONGTO is a GPS outdoor activity app for walking, running, hiking and trail running.

Contact

If you need help or encounter an issue, please contact:

clubmakers@naver.com

Core Features

  • GPS activity recording
  • Distance, time, pace and elevation tracking
  • Walking, running, hiking and trail-running activities
  • Route browsing and saving
  • GPX / TCX / FIT import
  • Activity history and monthly statistics
  • 3D route replay
  • Story creation and sharing

Troubleshooting

  • Check Location Services permission for WOONGTO if GPS recording does not start correctly.
  • For better GPS accuracy, start recording outdoors after location signals become stable.
  • If route import fails, verify that the GPX / TCX / FIT file is valid and not corrupted.
  • When contacting support, include your iPhone model, iOS version and a screenshot if possible.
