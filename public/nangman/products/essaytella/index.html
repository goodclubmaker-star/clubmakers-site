02 / FEATURES06 KEY FEATURES

PRODUCT GUIDE

핵심 기능을
자세히 살펴보세요.

01

글 유형 선택

작성하려는 글의 종류를 선택합니다. 글의 목적과 형식을 미리 정해 일관된 초안을 만드는 흐름입니다.

02

주제와 상황 입력

어떤 이야기를 하고 싶은지 소재와 상황, 포함할 내용을 적어 글의 중심을 결정할 수 있습니다.

03

표현 톤 선택

표현 방식과 문장의 분위기를 고르는 옵션을 제공합니다. 전달하려는 감정과 독자를 고려해 글의 결을 맞춥니다.

04

글 생성

입력한 조건을 바탕으로 초안 텍스트를 구성합니다. 원하는 방향을 구체적으로 적을수록 내용을 조절하기 좋습니다.

05

문장 재조정

생성된 글을 살펴보면서 표현을 바꾸거나 다시 요청할 수 있도록 구성된 화면을 제공합니다.

06

최종 글 확인

완성된 글을 읽고 스스로 수정하며 활용할 수 있습니다. 개인 API 설정 등은 서비스 화면 안내에 따라야 합니다.

HOW TO USE
